### [SPRINT-006] Удаление в списке патогенезов: смена семантики (связь, а не запись)
- **Подробное описания**: Бэкенд (SPRINT-001 backend) перестаёт удалять системные записи `diseases`: `DELETE /pathogenesis/{id}` теперь снимает только связь пользователя (`disease_users`). Фронт: обновить тексты модалки подтверждения («Убрать из моих» вместо «Удалить патогенез?»), сообщения об ошибке и обработку результата — запись остаётся в системе, просто исчезает из списка текущего пользователя.
- **Приоритет**: high
- **Статус**: done
- **Связанные файлы**: `src/pages/pathogenesis-main/ui/pathogenesis-main-page.tsx`, `src/shared/api/pathogenesis.ts`, `src/shared/config/i18n/resources/pathogenesis.ts`
- **Ограничения**: API-метод остаётся `DELETE /pathogenesis/{id}` (меняется только серверная семантика); системные записи не удаляются.
- **Ожидаемый результат**: «удаление» из списка не трогает общую запись; другие пользователи продолжают видеть её; тексты и сообщения обновлены.
- **Что сделано**: i18n (en/ru): `deleteTitle` → «Remove from my list? / Убрать из моих?», `deleteConfirmBody` → «…останется в системе», `delete` → «Remove / Убрать», `deleteError` → «не удалось убрать из списка». Кнопка подтверждения в модалке использует `delete` (теперь «Убрать»). Обработка результата не менялась — после успешного `DELETE` список перезагружается, запись остаётся в системе. Проверено: `npm run lint` — 0 errors, `npx tsc -b` — OK.
- **Не сделано**: —

### [SPRINT-007] Личное название заболевания (`disease_users.name`)
- **Подробное описания**: С бэкенда в ресурсе списка появляется `user_name` (своё название пользователя из `disease_users`), иначе — системное `name`. Фронт: отображать `user_name`, где задан; (опц.) редактирование личного названия в UI списка.
- **Приоритет**: medium
- **Статус**: done
- **Связанные файлы**: `src/pages/pathogenesis-main/...`, `src/shared/api/pathogenesis.ts` (типы списка), i18n ресурсы `pathogenesis.ts`
- **Ограничения**: fallback на системное имя; API-контракт меняется только добавлением поля `user_name`; без изменения структуры существующих полей.
- **Ожидаемый результат**: пользователь видит и может задать своё название болезни; системное имя — дефолт.
- **Что сделано**: `DiseaseItem.userName: string | null` добавлен в тип; в `pathogenesis-main-page.tsx` добавлен `displayName(item) = userName || name` — используется в мобильных карточках (аватар + заголовок), в десктопной таблице и в модалке удаления.
