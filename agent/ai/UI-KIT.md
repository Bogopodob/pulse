# UI Kit

## Где лежит UI
- Компоненты: `src/shared/ui/`
- Стили/токены: `src/shared/styles/`
- Иконки: `src/shared/icons/`

## Какие компоненты уже есть
| Компонент | Путь | Когда использовать |
|---|---|---|
| Button | `ui/Button` | все кликабельные действия |
| Input | `ui/Input` | текстовые поля форм |
| Modal | `ui/Modal` | диалоги подтверждения |

## Какие компоненты использовать
- Всегда использовать heroui, очень сложные и кастомные брать компоненты из `ui/`, не создавать html-элементы напрямую (`<button>`, `<input>` и т.д.), если есть готовый аналог

## Какие компоненты запрещено писать с нуля
- ❌ Button, Input, Modal, Select — уже есть, использовать существующие
- ❌ Не создавать новую систему цветов/отступов — использовать токены из `styles/`
- Если нужного компонента нет — предложить пользователю, не создавать втихую
